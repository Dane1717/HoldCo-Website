## Deployment

### GitHub Pages (Interim)
1. Repo Settings → Pages → Source: GitHub Actions
2. Push to `main` — auto-deploys in ~1 min
3. URL: `https://dane1717.github.io/HoldCo-Website/`

### Render (Production)
1. Create Render account (free tier)
2. New Static Site → Connect `Dane1717/HoldCo-Website`
3. `render.yaml` auto-configures build settings
